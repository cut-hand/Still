# Still · 留选

面向 **macOS 27 / Apple silicon** 的原生照片筛选工具。参考 [Sift v1.0.2](https://github.com/sankigan/Sift/releases/tag/v1.0.2) 的 RAW + JPG 工作流程，使用 Swift 6、SwiftUI、Observation、Swift Concurrency、ImageIO 和 CryptoKit；无第三方运行时依赖。

## 运行

从 [Releases](https://github.com/cut-hand/Still/releases) 下载应用 ZIP，解压后打开 `Still.app`。本地构建产物位于 `dist/Still.app`。当前为 0.2.5 本机签名开发版，尚未进行 Developer ID 签名和 Apple 公证。应用声明简体中文本地化，系统文件选择器、菜单使用中文。

选择照片文件夹后，先扫描并显示扩展名组合、组数、文件数和示例，确认后导入；也可体验演示图库。递归扫描所有子文件夹；同名配对跨全部子文件夹，HEIF 与 RAW 分目录存放也归为同一组；去掉最后一个扩展名后同名的文件组成一组，包含可识别照片的组会导入，同名其他扩展名也作为关联文件一起归档。同名 HEIF（`.heif` / `.hif`）或 HEIC 与 RAW 也会配为一组，预览 HEIF / HEIC；同组同时有 JPG 时优先预览 JPG。HEIF / HEIC 保持原格式归档，不转换成 JPG；RAW 单文件的解码取决于系统 ImageIO 对具体相机格式的支持。

## 精选与星级

照片只有「精选」「淘汰」两种决策，未选择时保持中立。星级独立于精选与淘汰：可以给任意照片评 1–5 星，取消星级不会清除精选；标星后停留在当前照片。胶片条显示醒目的绿色勾号、红色叉号和状态边框，星级显示为黄色星号与数字。当前照片另有白色焦点框。

已移除底部整条操作栏、底部状态信息栏和侧栏底部宣传文字。选片、星级和连选操作使用快捷键或菜单。顶部保留紧凑的侧栏、归档和照片信息按钮。左侧栏可通过顶部按钮、显示菜单或自定义快捷键收起 / 展开。

## 默认快捷键

| 按键 | 操作 |
| --- | --- |
| A / D | 上一张 / 下一张；跳过行为可设置 |
| W / S | 向左 / 向右增加一张比较照片 |
| Shift+W / Shift+S | 从左 / 从右减少一张，至少保留一张；不改变照片标记 |
| 空格 | 完成本组，进入组后下一张；单张时跳过 |
| F / X | 切换精选 / 淘汰 |
| R | 清除精选或淘汰标记，保留星级 |
| 1 / 2 / 3 / 4 / 5 | 设为对应星级，不自动前进 |
| 0 | 取消标星 |
| ` / ~ / · 所在键 | 取消标星的第二按键，兼容中英文输入源 |
| B / I | 显示 / 隐藏左侧边栏 / 照片信息 |
| Esc | 离开比较，保留已点选标记，不结算本组 |
| ⌘Z | 撤销（包括星级、连选结算） |
| ⌘O / ⌘↩ / ⌘, | 打开文件夹 / 归档 / 设置 |

设置中的「快捷键」页可修改浏览、选片、星级、两种取消标星以及侧边栏的单键绑定，支持字母、数字、符号、空格，并检查冲突。

连选时点击照片切换精选，点击胶片条中本组照片可只改变当前焦点。空格完成本组，默认保留精选、其余全部标为淘汰；一张都没选时全组淘汰。也可在设置中关闭自动淘汰。星级不会自动视为精选。

鼠标移到照片上滚动滚轮可缩放（1–8 倍）；双击放大 / 复位，捏合缩放，放大后拖动查看。连选默认同步缩放倍率，可用顶部「倍率关联」开关关闭。

## 归档与恢复

归档面板提供两组选项，设置页可保存默认值：

- **按精选归档**：精选、淘汰（可恢复）、未选择分别放入不同目录。
- **按星级归档**：按 1–5 星和未标星分类；淘汰照片始终优先放入独立淘汰目录。
- **RAW 与 JPG / HEIF / XMP 同目录**：默认开启。关闭后，各分类目录内再分 RAW、照片、XMP。

选择目的位置、检查各分类数量，再点击「移动并归档」。每次创建唯一归档目录，保留文件原格式，不永久删除淘汰原片。归档前写入 `归档清单.json`，包含原位置、归档位置、精选状态、星级；发生错误时尝试回退。菜单「选片 → 从归档清单还原…」可恢复原位置，发现重名原文件时停止，避免覆盖。

进度自动保存在 `~/Library/Application Support/Still/Sessions/`；重新打开同一文件夹时恢复标记、星级和位置。旧版颜色标记迁移为精选，旧版「已跳过」迁移为未选择；旧版归档清单仍可还原。

## 构建与验证

需要 Swift 6.4 / macOS 27 SDK（Xcode 27 或相应 Command Line Tools）。

```sh
swift build
./Scripts/test.sh
./Scripts/build-app.sh
open dist/Still.app
```

`Scripts/test.sh` 为部分 Command Line Tools 环境显式载入 Swift Testing 宏插件；完整 Xcode 中可直接 `swift test`。测试覆盖连选、独立星级、旧版迁移、RAW/JPG/XMP 配对、两种分类 × 两种目录布局、原文件完整性、重名保护及恢复。

`Scripts/build-app.sh` 生成 Release 应用、中文本地化配置、图标和本机签名。`Package.swift` 可直接用 Xcode 打开。

图标源文件：`Design/Still-logo.svg`、`Scripts/make-icon.swift`、`Design/Still-1024.png`。

胶片条支持垂直滚轮转为横向滚动。浏览模式、当前位置、连选提示移至左栏；照片名称、格式、倍率和星级在角落浮层显示，不占用额外照片高度。

导入确认中每种扩展名组合前提供复选框，默认全选；取消的组合不会导入或归档。多图比较提供「倍率关联」与「移动关联」两个独立开关，默认均开启；移动按各预览区域的比例同步。跨目录重名文件完整保留，归档时增加副本后缀防止覆盖。

没有配对的 JPG、HEIF、RAW 也作为单格式组导入。左侧下半部可按扩展名组合切换显示，默认全部勾选；隐藏不修改标记，重新勾选恢复。设置支持胶片序列号 / 原文件名，以及滚轮每格 1–20 个百分点（默认 2）的缩放步进。提示统一在左栏展示。

0.2.5：组合切换按照片 ID 重建胶片条；顶部使用紧凑的侧栏、归档和照片信息按钮；显示菜单支持左右栏开关。选片菜单涵盖全部浏览、标记、星级、连选和关联操作，并显示自定义快捷键。帮助菜单打开内置使用指南和当前快捷键表。已移除工作空间 / 照片图库装饰区域。

## 发布打包

运行 `./Scripts/package-release.sh` 构建应用并生成 `dist/Still-v版本号-macOS-arm64.zip` 和 `dist/SHA256SUMS.txt`。仅支持 Apple silicon；不包含 Intel 版本。应用在本地处理文件，不上传照片。
